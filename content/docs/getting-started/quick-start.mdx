This guide will walk you through recording your first test case and replaying it against your local application using Vantage's zero-code reverse proxy.

Because Vantage operates at the network level, it works out of the box with **any backend language or framework** (Express, FastAPI, Django, Go, Spring Boot, Rails, etc.) without altering a single line of your application code.

## 1. Install Vantage

Install the Vantage CLI globally or in your project:

```bash
npm install -g vantage-cli
```

*(Alternatively, you can run commands directly using `npx vantage-cli`).*

## 2. Record Traffic (Zero Code)

To start recording, run `vantage record` with the `--proxy` flag pointing to your application's port. You can use `-c` to have Vantage automatically boot your app for you:

```bash
vantage record -c "npx tsx server.ts" --proxy 3000
```

### What happens behind the scenes:
1. Vantage spins up a transparent reverse proxy listening on port `6789`.
2. It launches your application server (listening on port `3000`).
3. It prepares a fresh test set (e.g. `.vantage/test-set-1/`).

### Generate Some Traffic

Now send requests to the **Vantage Proxy Port (6789)** instead of your application port. You can use curl, Postman, or your frontend client:

```bash
curl http://localhost:6789/api/users
```

The reverse proxy forwards the request to your application on port `3000`, relays the response back to your client, and saves the request/response pair:

```text
 ⚡ Vantage: INFO    Created test-set-1
 ⚡ Vantage: INFO    Record server listening on port 6789...
 ⚡ Vantage: INFO    Spawning target app: npx tsx server.ts
 ⚡ Vantage: SUCCESS get-api-users-1  <- /api/users
```

Make as many requests as you want to simulate real user behavior. When you are done, press <kbd>q</kbd> in your terminal to stop recording.

## 3. Replay Tests

Now that you've captured baseline traffic, replay it to verify your API behavior and catch regressions:

```bash
vantage test -c "npx tsx server.ts" --target http://127.0.0.1:3000
```

Vantage will:
1. Boot your application server.
2. Replay every captured request directly against your app (`http://127.0.0.1:3000`).
3. Diff the actual response status, headers, and JSON body against the recorded baseline (automatically ignoring noise like timestamps and UUIDs).
4. Output a summary report.

You just recorded and replayed an end-to-end API test suite without modifying your application code or writing manual assertions.
