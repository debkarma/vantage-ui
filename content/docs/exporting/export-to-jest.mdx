---
title: Export to Jest
description: Generate native Jest and Supertest test suites from your recorded traffic.
---

While Vantage's built-in test runner is incredibly fast and powerful, you might want to integrate your tests into an existing JavaScript testing ecosystem. Vantage allows you to export your recorded YAML test sets into native `jest` and `supertest` code.

## Generating the Code

To export your test suite to Jest, run the `export` command and specify the path to your Express app's entry file:

```bash
vantage export --format jest --app-entry ./src/app.ts --output ./tests/generated
```

## How It Works

Vantage reads your YAML files and translates them into an equivalent `supertest` implementation. 

If your test set looks like this:

```yaml
method: POST
path: /api/users
headers:
  authorization: Bearer my-token
request_body:
  name: Alice
response:
  status: 201
```

Vantage generates this native Jest test:

```typescript
import request from 'supertest';
import app from '../src/app';

describe('Vantage Test Suite', () => {
  it('POST /api/users', async () => {
    const response = await request(app)
      .post('/api/users')
      .set('authorization', 'Bearer my-token')
      .send({ name: 'Alice' });

    expect(response.status).toBe(201);
  });
});
```

## Benefits of Jest Export

- **In-Memory Testing**: `supertest` binds directly to your Express app instance without spinning up a real HTTP server on an open port. This allows the tests to run extremely fast.
- **Zero Vendor Lock-in**: You own the generated code. If you ever decide to stop using Vantage, you still have a full, native test suite that you can commit to your repository and maintain manually.
