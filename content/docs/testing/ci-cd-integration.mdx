Vantage is designed to run seamlessly in Continuous Integration (CI) environments. It can spin up your app, run the tests, and output machine-readable reports.

## The `--ci` Flag

When running in a pipeline, always use the `--ci` flag. This disables interactive terminal formatting (like spinners and colors) and ensures the exit code correctly reflects the test suite's status.

```bash
vantage test --ci -c "npm start"
```

## GitHub Actions

Here is a complete workflow file for running Vantage in GitHub Actions.

```yaml
name: Vantage Tests

on:
  push:
    branches: [ "main" ]
  pull_request:
    branches: [ "main" ]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      
      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          
      - name: Install dependencies
        run: npm ci
        
      - name: Install Vantage
        run: npm install -g vantage-cli
        
      - name: Run Vantage Tests
        run: vantage test --ci -c "npm start"
```

> [!TIP]
> If your application uses Testcontainers, ensure your GitHub Actions runner has Docker installed and running. (The `ubuntu-latest` runner comes with Docker pre-installed).

## GitLab CI

Here is an equivalent configuration for GitLab CI:

```yaml
vantage_tests:
  image: node:20
  stage: test
  services:
    - docker:dind # Required if using Testcontainers
  variables:
    DOCKER_HOST: tcp://docker:2375
  script:
    - npm ci
    - npm install -g vantage-cli
    - vantage test --ci -c "npm start"
```
