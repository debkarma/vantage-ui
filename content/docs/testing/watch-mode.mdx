title: Watch Mode
description: Run Vantage continuously for a seamless Test-Driven Development (TDD) workflow.
---

Vantage includes an integrated **Watch Mode** that continuously monitors your codebase and re-runs your API test suites whenever you save a file. This provides instant feedback without manual terminal switching.

## Starting Watch Mode

Append the `--watch` flag to `vantage test`, along with your server startup command:

```bash
vantage test --watch -c "npm run dev"
```

You will see the interactive terminal switch to live monitoring:

```text
[WATCHING] Waiting for file changes to re-run tests...
```

---

## How Watch Mode Works

When `--watch` is active, Vantage manages a continuous feedback loop:

1. **Recursive File Watcher**: Monitors your project directory for filesystem events using native OS watchers.
2. **Built-in Ignore Rules**: Automatically ignores changes within `.vantage/`, `node_modules/`, and Python's `__pycache__/` to prevent endless loops.
3. **500ms Debounce**: Debounces rapid file changes (e.g. IDE auto-saves or bulk formatters) into a single atomic execution.
4. **Execution Guard**: If a test run is currently in flight, file changes are held until the active run completes, preventing process race conditions.
5. **Clean Teardown & Re-run**:
   - Safely kills the running server process (`killApp`).
   - Executes your `post_test` script (if configured).
   - Spins down ephemeral Testcontainers.
   - Boots fresh containers, applies dynamic database URLs, runs `pre_test` migrations, restarts your server, and executes the suite.

## Focused TDD with `--test-set`

When actively developing or fixing a bug in a specific endpoint, you don't need to re-run your entire history. Target a single test set in watch mode:

```bash
vantage test --watch --test-set test-set-0 -c "npm run dev"
```

Every time you modify your business logic or schema, Vantage will instantly verify that specific contract.

---

## Combining Watch Mode with Testcontainers

Watch Mode pairs seamlessly with Vantage's Testcontainers integration. Because Vantage manages the database container lifecycle automatically, each file save tests against a clean, isolated database state—meaning tests never fail due to dirty state left over from a previous manual run.
