---
title: Global Flags
description: Flags that apply to all Vantage commands.
---

The following flags can be appended to any `vantage` CLI command.

## Options

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--version` | boolean | false | Print the current CLI version and exit. |
| `--help` | boolean | false | Print the help menu for a specific command and exit. |
| `--debug` | boolean | false | Enable verbose logging for troubleshooting Vantage internals. |

## Examples

```bash
vantage record --help
```

```bash
vantage test --debug -c "npm start"
```
