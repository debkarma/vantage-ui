---
title: vantage list
description: View all recorded test sets.
---

The `list` command scans your `.vantage` directory and outputs a summary of all available test sets.

## Synopsis

```bash
vantage list
```

## Output Example

```text
Found 3 test sets in .vantage/:

- test-set-1 (14 tests)
- auth-workflow (2 tests)
- payment-failures (5 tests)
```
