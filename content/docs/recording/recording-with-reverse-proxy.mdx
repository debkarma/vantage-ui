Vantage records API traffic using a lightweight, transparent reverse proxy. This architecture is **completely language-agnostic and requires zero code changes**—whether your backend is built with Node.js, Python, Go, Java, Ruby, or Rust.

## How the Proxy Works

Instead of requiring code modifications or proprietary SDKs, Vantage sits in front of your application server. You send your HTTP requests to the Vantage proxy port, which records each request and its real response before forwarding it to your backend.

## Starting a Recording Session

To start recording, run `vantage record` with:
- `-c` (or `--command`): The command that starts your application.
- `--proxy`: The port your application server listens on.

```bash
vantage record -c "npm run dev" --proxy 3000
```
