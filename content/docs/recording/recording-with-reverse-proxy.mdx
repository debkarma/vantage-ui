If your backend is written in Python, Go, Ruby, or any language other than Node.js, you can use the Vantage Reverse Proxy to intercept traffic. This mode is completely language-agnostic and requires zero code modifications to your application.

## How the Proxy Works

Instead of modifying your code, Vantage spins up a lightweight proxy server that sits in front of your application. You send your HTTP requests to the proxy, which records the transaction and forwards it to your actual backend.

## Starting the Proxy

To start recording via the reverse proxy, use the `vantage record` command and specify the port your application is running on using the `--proxy` flag.

```bash
vantage record -c "python main.py" --proxy 5000
```

In this example:
1. Vantage runs your server startup command (`python main.py`).
2. Your server starts on port `5000`.
3. Vantage starts a proxy server on port `6789`.
4. You send your API requests to `http://localhost:6789`.

## FastAPI Example

Here is how you would record traffic for a standard Python FastAPI application:

```bash
# Start Vantage in proxy mode
vantage record -c "uvicorn main:app --port 8000" --proxy 8000
```

Now, instead of sending your requests to `localhost:8000`, send them to `localhost:6789`. Vantage will record the incoming request, forward it to your FastAPI server, capture the response, and generate a reproducible test case.
